关于我和这个博客
1 min · 15 words · 南极林

你好，我是南极林，一个开发者。

这个博客记录三样东西：技术、生活和思考。正如首页写的：用文字对抗遗忘，用分享连接世界。

  • 技术：写真正在工作中用到的工具和方法，尽量是踩过坑之后的第一手经验，不写重复的教程。
  • 生活：想到什么写什么，随缘更新。
  • 思考：把想不明白的事写下来，写着写着就明白了。

博客用 Hugo + GitHub Pages 搭建，纯静态、零成本，源码在 GitHub。

想交流的话，可以在 GitHub 上找到我：@antarctlin。
